# 📊 CSAT Analytics – Customer Satisfaction Analysis

## 📌 Project Overview

The CSAT Analytics project analyzes customer support call data to understand customer satisfaction, call trends, response times, SLA performance, customer sentiment, and support-channel performance.

The project was developed using Power BI to transform raw customer service data into an interactive dashboard and generate meaningful business insights.

---

## 🎯 Project Objectives

- Analyze overall customer satisfaction.
- Identify daily call trends.
- Analyze customer sentiment.
- Compare performance across different channels.
- Evaluate SLA and response-time performance.
- Identify major reasons for customer calls.
- Analyze CSAT ratings across different dimensions.
- Identify areas for improving customer service operations.

## 🔎 Key Insights

### CSAT Rating Coverage

- Total Calls: 32,941
- Rated Calls: 12,271
- Not Rated / CSAT 0: 20,670
- CSAT Rating Rate: 37.25%

A significant number of customer interactions did not receive a CSAT rating, which highlights an opportunity to improve feedback collection.

### Customer Sentiment

- Negative: 11,063
- Neutral: 8,754
- Very Negative: 6,026
- Positive: 3,928
- Very Positive: 3,170

### Call Reasons

- Billing Question: 23,462
- Payments: 4,749
- Service Outage: 4,730

Billing-related queries represent the largest call-reason category.

### Channel Distribution

- Call Center: 10,639
- Chatbot: 8,256
- Email: 7,470
- Web: 6,576

### SLA Performance

- Within SLA: 20,625
- Below SLA: 8,148
- Above SLA: 4,168
